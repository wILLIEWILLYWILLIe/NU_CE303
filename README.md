This repository contains coursework and homework assignments for **CE303 Advanced Digital Design**. The projects utilize industry-standard Electronic Design Automation (EDA) tools.

## 🛠️ Environment Setup

To initialize the Cadence EDA tool environment (including [Cadence Genus](https://www.cadence.com/en_US/home/tools/digital-design-and-signoff/synthesis/genus-synthesis-solution.html) for logic synthesis and [Cadence Xcelium](https://www.cadence.com/en_US/home/tools/system-design-and-verification/simulation-and-testbench-verification/xcelium-simulator.html) for hardware simulation), source the provided script from the repository root:

```bash
source env_cadence.csh
```
